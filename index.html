04 / Usage guide

Three rules for prompt engineering.

The protocol is simple enough to be misunderstood at scale.

01

Ask loudly.

If the request is impossible, make sure it is also specific and written in all caps somewhere.

02

Skip the middle.

Why learn, build, or wait when a properly phrased prompt could simply solve the entire thing?

03

Blame the model.

When the answer is inconvenient, remember: the prompt was probably perfect.
